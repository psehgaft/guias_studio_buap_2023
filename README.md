# Guías de estudio BUAP

Colección de guías de estudio y exámenes de práctica para el proceso de admisión de la **BUAP (Benemérita Universidad Autónoma de Puebla)**. Reúne guías oficiales organizadas por área de conocimiento, de distintos años, además del temario oficial y material de apoyo.

### Otros materiales

- `Temario_BUAP.pdf` — temario oficial del examen de admisión.
- `paa prueba.pdf` — prueba de aptitud académica de práctica.
- `GUÍA BUAP - 2017.pdf` — guía general de admisión 2017.
- `Física universitaria.docx` — material de apoyo de física.

## Cómo usar este repositorio

1. Identifica el área o nivel al que vas a aplicar (licenciatura o preparatoria).
2. Descarga la guía más reciente de tu área (las guías 2022 y las guías PAD son las más actuales).
3. Revisa el temario oficial (`Temario_BUAP.pdf`) para conocer los temas a estudiar.
4. Resuelve las guías como exámenes de práctica cronometrados.
